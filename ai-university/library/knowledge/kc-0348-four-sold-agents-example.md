# Worked example: four sold AI agents and why prices differed

**What:** A concrete ladder of four AI-agent products sold to businesses, each
priced higher as scope and demonstrated value grew — useful raw material (abstract
it, don't reuse the story) for teaching how automation value maps to price.

**Why it matters:** It grounds ROI/value-based pricing in real product types and
shows a key nuance: value that compounds (sales/revenue-generating) should be
priced higher than value that's flat (administrative), even when the admin build
feels comparable in effort.

**The moves (the four builds, as reference):**
1. A personalized outreach agent — researches each contact/company and drafts
   tailored outreach + follow-ups into a database (doesn't send). ~$1,650, priced
   almost arbitrarily as a beginner but still a clear ROI win.
2. A sales/quote agent — handles inquiries, generates quotes, logs full details to
   the CRM; cuts manual entry and errors and defers hiring. ~$4,000.
3. An internal personal-assistant agent — data retrieval, task management, and
   productivity inside the team's chat tool. ~$6,000, but priced on build
   complexity rather than value.
4. A full AI concierge — member onboarding, event help, guest passes, support, with
   conversation history; incorporated newer tech as a value lever. ~$12,000.

**Watch out for:** The teller later judged the sales agent should have been priced
above the personal assistant, because sales value compounds (more conversions →
more growth → more usage) while admin value stays flat — a lesson about pricing on
compounding value, not effort.
