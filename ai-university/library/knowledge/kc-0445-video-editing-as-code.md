# AI video editing as code: animate HTML, render to video

**What:** A coding agent can edit and animate video by writing HTML/CSS that gets rendered to a video file. Text overlays, subtitles, motion graphics, charts, and repositioning your face-cam are all produced from natural-language instructions rather than a manual editor. The underlying pipeline goes from HTML in a browser through a video encoder to a finished file.

**Why it matters:** Edits that would take a skilled editor hours (keyframing motion graphics on a short clip) can be produced in minutes, and because it's just HTML — which agents are very good at generating and animating — the approach is broadly capable.

**The moves:**
1. Understand the core: the tool creates HTML, animates it, and renders it to a video file via an encoder.
2. Describe the edit you want in plain language (overlays, captions, graphics that sync to the audio).
3. Choose your route: a hosted design app for speed, or a code-based framework for more control and power.
4. Preview, then render to a standalone video file.

**Watch out for:** These tools amplify existing editing taste rather than replacing it — someone with a good sense of pacing and transitions gets far more out of them than someone with none.

**Original example to invent:** Source shows a branded intro and sizzle reel. Writers should invent a different short edit (e.g., an explainer with a chart overlay) and describe the HTML-to-render flow abstractly.
