# The AI generalist and the four powers

**What:** A framing that value is shifting toward generalists who can span many functions using AI, rather than deep single-domain specialists — because AI lets one person pick up new skills in days instead of years. The generalist's capability is organized into four "powers," each unlocked by a small set of tool categories.

**Why it matters:** It reframes tool-learning as skill-acquisition and gives a coverage checklist so you don't over-invest in one narrow craft that could be automated.

**The moves — the four powers and their tool categories:**
1. **Build** — make apps and websites from natural-language descriptions (app builders; graduate to an AI code editor for control).
2. **Automate** — combine AI tools/agents, workflow-automation platforms, prompt engineering, and API testing into a connected system that runs with little involvement.
3. **Create** — generate images, video, UI designs, icons/brand systems, and edited video.
4. **Connect** — use AI-assisted writing to scale content and reach an audience (the multiplier on all the others).

**Watch out for:** Specific tool picks have a short shelf life; the durable asset is the four skill categories, not any one product. The "adapt vs. specialize" argument is asserted, not proven.

**Original example to invent:** The source leans on extended animal/evolution analogies (specialists going extinct, adaptable generalists surviving). Do not reuse; if you need a framing, state the adapt-over-specialize idea plainly.
