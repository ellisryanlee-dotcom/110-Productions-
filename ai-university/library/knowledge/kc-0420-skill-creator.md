# Skill Creator: the skill that builds every other skill

**What:** An official skill that lets you describe a job in plain English (or hand it an existing SOP) and have the agent draft, test, iterate, and package a reusable skill — so you never hand-edit skill files or wrestle with formatting.

**Why it matters:** Most people who try to write skills manually hit a wall on structure and reliability and either quit or produce something that breaks the moment a client touches it. Skill Creator removes that learning curve, and every downstream skill you sell comes out of it — it's the factory that makes the products.

**The moves:**
1. Install it, ideally at a user/global scope so it's available in every project without thinking about it.
2. Describe the desired job conversationally, as if briefing a coworker, or drop in an existing SOP document.
3. Let it draft, test, and iterate the skill, then package it for reuse.
4. Reuse the packaged skill so the job runs the same way every time.

**Watch out for:** The created skill itself usually isn't what a client pays for — its value is indirect, as the tool that makes all your other billable skills possible.

**Original example to invent:** Source uses property-description generation for a real-estate agency. Writers should invent a different SOP-to-skill conversion (e.g., an onboarding-email generator).
