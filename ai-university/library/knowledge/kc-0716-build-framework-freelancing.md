# BUILD: freelancing with automation templates

**What:** A five-step framework for making your first money by adapting existing
automation templates rather than building from scratch. BUILD = Block by block
(master one template at a time), Understand the use case (which businesses that
template helps most), Install and imitate (import it, run with test data until you
know every step, then record a short demo), Land the first client (reach out to
businesses that clearly need that outcome), Document and duplicate (measure before/
after results into a case study, then repeat with the next template).

**Why it matters:** Templates lower the technical barrier so beginners can deliver
value fast, but the real skill is customizing a template and framing its business
value. Mastering one "block" at a time avoids overwhelm and builds credibility
offer by offer.

**The moves:**
1. Pick one template and learn it deeply before adding another.
2. Identify the specific businesses whose pain it solves.
3. Run it on test data, then make a ~60-second demo of the value.
4. Pitch only businesses that need that exact outcome, offering to set it up.
5. Capture time saved / errors reduced / revenue gained as a case study, then add
   the next block.

**Watch out for:** You can't resell a raw template — you must customize it to the
client's industry and voice. Income here typically caps in the mid/high four
figures per month until you move up to consulting or retainers.

**Original example to invent:** Choose one template type, name three niches it
fits, and script the outreach pitch and demo outline for one of them.
