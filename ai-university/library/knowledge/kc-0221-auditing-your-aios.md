# Auditing and leveling up your agent operating system

**What:** Two companion skills that keep an agent OS improving. An audit skill scores
the system against the Four C's (context, connections, capabilities, cadence),
surfaces the biggest gaps ranked by leverage, and can be saved over time to track
progress. A level-up skill interviews you about your week to find the next thing worth
automating.

**Why it matters:** People stall because they don't know what to build next. A
repeatable audit turns a vague "make it better" into a scored gap list with a ranked
next action; the level-up questions guarantee you always find an automation candidate.

**The moves:**
1. Run the audit to get a per-pillar score and the top gaps by leverage.
2. Save each audit so you can see the system improving over time.
3. Run level-up and answer a few reflection questions: what did you do 3+ times this
   week? what felt manual/boring? what could a smart intern have handled? what would
   break if demand spiked? what would move growth if it ran on autopilot?
4. Turn each answer into a new connection, skill, or automation.
5. Re-audit on a cadence (e.g., weekly) to plan the next steps.

**Watch out for:** Early scores can be generous/relative to how new the system is —
read the gap list, not just the number. The most leverage usually comes from the
capabilities pillar (custom skills), which early setups score lowest on.
