# Automate events, not on-demand tasks, for real leverage

**What:** The highest-leverage automations are triggered by real-world events and run without you — a new lead form, an incoming payment, a new email — rather than systems that only act when you sit down and prompt them. Event-driven systems "wake up" on their own, take action, and run day and night.

**Why it matters:** The point of automation is leverage: time saved without your involvement. An assistant you have to talk to creates little leverage; an event-triggered workflow scales. There's also a compounding effect — a system that saves time and grows the business gets used more, creating a flywheel of value and rising ROI.

**The moves:**
1. Bias toward building things that run while you sleep, not things that wait for a button press or a conversation.
2. Anchor each automation to an event trigger (form submission, payment, inbound message) rather than manual invocation.
3. Look for flywheel candidates: automations whose usage grows as the business grows.
4. Focus beginners here first — event-driven leverage is where scale comes from.

**Watch out for:** Convenience tools that only act on request feel productive but don't scale. Not every valuable task is a good automation if it can't be triggered autonomously (pair with the four-pillar test).

**Original example to invent:** The source contrasts an on-demand personal assistant with event-triggered workflows. Writers should invent a specific event-driven automation and trace its flywheel effect.
