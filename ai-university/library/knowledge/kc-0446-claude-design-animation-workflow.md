# Make animated videos in a hosted design app

**What:** A hosted design app can produce timeline-based motion design — animated graphics, and video with synced text/graphics on top — from a prompt. It asks clarifying questions (talking-head placement, energy level, graphic types, theme, aspect ratio) and generates the piece. You can screen-record the preview, or hand a command to a coding agent to render a downloadable video file.

**Why it matters:** It's the lower-setup route to branded animated video: fast, guided by good questions, and capable of impressively fast-paced output.

**The moves:**
1. Start from an animation template and drop in any source video.
2. Prompt for what you want (animate this clip with synced text and motion graphics that illustrate what's being said).
3. Answer its setup questions: face-cam placement, visual energy, motion-graphic types, theme, and orientation.
4. To sync graphics accurately, paste in a transcript with timestamps (the app can't hear or read the video's audio on its own).
5. Export by screen-recording the preview, or copy its hand-off command into a coding agent and have it render an MP4.

**Watch out for:** The key limitation is it cannot listen to or transcribe the video, so without a timestamped transcript it can't align text and graphics to the words. If the setup questions time out, it falls back to defaults and quality drops.

**Original example to invent:** Source animates a short talking-head clip about workflows. Writers should invent a different source clip and prompt, and describe the transcript-sync step abstractly.
