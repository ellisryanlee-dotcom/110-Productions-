# Volume equals value: where AI automation is worth the most

**What:** A heuristic for choosing which tasks to automate for a client: even a basic operation becomes highly valuable when it's performed at high volume. A simple task done thousands of times a month (e.g., cleaning up and formatting text before it's sent) can justify meaningful fees because AI performs it tirelessly and fast.

**Why it matters:** It redirects beginners away from flashy-but-rare tasks toward mundane, high-frequency ones where AI's tirelessness compounds into real ROI. High-volume tasks are also easier to price because the time/cost saved is large and demonstrable.

**The moves:**
1. When auditing a business, look for tasks repeated at high frequency, not just impressive ones.
2. Estimate the aggregate time or cost the task consumes across all its repetitions.
3. Target those high-volume tasks first — the value case writes itself.
4. Keep an eye on per-run API costs; at high volume they add up (there are usually ways to reduce them substantially).

**Watch out for:** A high-volume automation's per-run cost matters; margins can erode if usage costs aren't optimized. Reliability also matters more at volume, since errors multiply.

**Original example to invent:** The source uses a specific invoice-text-cleanup case across franchise locations. Writers should pick a different high-volume task to illustrate the principle.
