# Add skills and import pre-built agent teams instead of starting from zero

**What:** Two reuse mechanisms for standing up capable agents fast. Skills are packaged
capabilities you attach by pasting a path/URL (e.g., from a public skills marketplace)
either to a single agent or to a whole company — for example a front-end design skill
or design-guidelines skill. Company templates are ready-made agent organizations you
import that arrive complete with their agents, skills, and knowledge, so you begin from
a staffed team rather than an empty one.

**Why it matters:** You don't have to build every capability or org chart by hand.
Skills bolt on domain competence in seconds; importing a template gives you an entire
pre-configured team (sometimes dozens of role-based agents) as a starting point you can
then customize.

**The moves:**
1. Find a skill (e.g., on a skills marketplace) and add it by pasting its path to an
   agent or company.
2. Layer multiple complementary skills where useful.
3. To start fast, import a pre-built company template that includes agents, skills, and
   knowledge.
4. Customize the imported roster to your needs.

**Watch out for:** Adding third-party skills or templates means running code/config you
didn't write — even with marketplace security audits, you can't be fully certain, so
vet what you install. More isn't always better; only add skills the role actually needs.
