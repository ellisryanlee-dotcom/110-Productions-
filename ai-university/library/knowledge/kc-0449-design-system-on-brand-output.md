# Enforce your brand with a design system

**What:** By giving the tool a design system — your logos, colors, typography, and buttons — every video, website, or asset it produces comes out consistently on-brand and matching your real site. You can also start from an existing standalone page's HTML and have it turned into an animated, on-brand release video.

**Why it matters:** Consistency is what makes generated output look intentional and owned rather than generic; a design system means you define the look once and everything inherits it.

**The moves:**
1. Set up a design system capturing logos, colors, typography, and UI elements.
2. Let the tool reference it so new outputs automatically match your brand.
3. To repurpose existing work, export a page to standalone HTML and hand it in with a prompt to animate it into a release video.
4. Keep prompts light once the design system is in place — the branding carries through.

**Watch out for:** A missing or thin design system yields generic-looking output; invest in defining it up front so everything downstream benefits.

**Original example to invent:** Source reuses a community's branding and a landing page's HTML. Writers should invent a different brand kit and a page-to-video repurpose.
