# Front-end design skill: make agent-built UIs look less AI-generated

**What:** An official front-end design skill that raises the visual quality of anything the agent designs — websites, slide decks, UI — so outputs read as intentional rather than obviously machine-generated.

**Why it matters:** Default agent-built interfaces often look generic; this skill closes much of that taste gap without you hand-tuning every element.

**The moves:**
1. Install it, ideally globally, so it applies whenever you design something.
2. Let it shape design work so outputs look more polished and less templated.
3. If you start a design in a dedicated design product and bring it back into the coding agent, apply this skill there to keep the quality.

**Watch out for:** It improves aesthetics but isn't a substitute for actual design direction — you still supply the taste and intent.

**Original example to invent:** Source mentions slide decks and websites generally. Writers should show a specific before/after (e.g., a landing page) illustrating the polish difference.
