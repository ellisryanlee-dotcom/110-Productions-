# Getting Claude Code running inside VS Code

**What:** The fastest beginner path to a coding-agent workspace: install a free
IDE, add the agent extension, sign in with a paid model subscription, and open a
project folder so the agent has a working directory. The layout is files on one
side, the agent chat on the other.

**Why it matters:** Newcomers stall on environment setup. This removes that
friction — no local coding required — and establishes the mental model that the
agent always operates *inside a project folder*, which is what everything else
(context files, skills, tools) depends on.

**The moves:**
1. Download and install a free IDE.
2. Add the coding-agent extension from the extensions marketplace and sign in with
   a paid model account (a paid tier is required; the entry plan works, higher
   tiers raise usage limits).
3. Create a dedicated folder for the project and open it as the working directory.
4. Open the agent panel; confirm it responds, then start adding files.
5. You can run several agent sessions/tabs at once against different files.

**Watch out for:** You cannot work without an opened folder — the agent needs a
project. Heavy use will hit usage limits on the entry plan; expect to upgrade. The
same setup works in other IDEs or the desktop app; the IDE choice is not load-bearing.

**Original example to invent:** Source opened a "YouTube analysis" folder. Writers
should demonstrate with a different first project (e.g., a "weekly-reports" folder).
