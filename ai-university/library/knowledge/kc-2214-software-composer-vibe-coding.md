# The "software composer": selling vibe-coded tools and MVPs

**What:** A service model where you don't write software so much as *describe and architect* it, using AI coding tools to generate internal dashboards, simple apps, and MVPs for small businesses that are running on spreadsheets and clunky software. Your role is the architect; the AI is your on-demand development team.

**Why it matters:** The barrier to building useful custom tools has dropped dramatically, so non-coders can deliver software-shaped value. Small businesses will pay well for a custom tool that consolidates messy systems and saves hours weekly.

**The moves:**
1. Start inside a general chat tool's coding ability for small tools you can whip up quickly.
2. Graduate to a professional AI-in-editor tool when projects get bigger and need more power.
3. Sell simple internal dashboards / MVPs to businesses drowning in spreadsheets.
4. Bundle "get your first client" motions (warm outreach) with the build skill.

**Watch out for:** In-chat vibe coding has limits — it won't build large production systems, so match tool to project size. Generated code still needs testing and a human who understands what it does before handing it to a client.
