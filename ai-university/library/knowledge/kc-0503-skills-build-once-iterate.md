# Skills: build once, then iterate every time you use them

**What:** A skill is a reusable, saved workflow — often just a markdown file describing a repeatable task — that lets an agent load subject-matter expertise into any session instantly. Skills range from a single reliable prompt up to multi-step workflows. Many are also publishable/shareable, and marketplaces of pre-built skills exist so you don't always start from scratch.

**Why it matters:** Anything you write or do repeatedly (a Monday-morning routine, a report format, an image generation recipe) is wasted effort if you re-explain it each time. Skills capture that once and make it faster and more consistent forever, and they carry across contexts (chat, co-work, coding harness).

**The moves:**
1. Notice repetition. When you keep typing the same prompt or doing the same task, convert it into a skill.
2. Capture good output in the moment: when the agent does something you like, tell it to turn that into a skill.
3. Don't expect perfection on the first run — a skill is a draft.
4. Every time you run it, give feedback ("keep this, drop that, update the skill") so it improves with your changing preferences, new models, or new endpoints.
5. Search existing skill libraries before building; install and customize rather than reinventing — but vet the source before trusting downloaded skills.

**Watch out for:** There's no "finished" skill — models, endpoints, and your preferences drift, so treat every use as data for the next revision. Only install skills from sources you trust.
