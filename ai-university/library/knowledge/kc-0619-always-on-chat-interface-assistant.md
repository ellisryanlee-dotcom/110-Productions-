# An assistant you reach from a chat app feels ambient and proactive

**What:** Wrapping an agent in a familiar chat channel (a messaging app, a team chat)
changes how it feels to use. Instead of sitting at a terminal or IDE, you can message
it from anywhere — your phone, in bed, at a restaurant — and it lives always-on so it
can also act proactively: reminding you of things, watching your projects, and taking
work overnight. A lightweight dashboard can complement the chat for reviewing what it
did.

**Why it matters:** Everyday usability is largely about the interface. A terminal is
comfortable for developers but intimidating and location-bound for everyone else. A
chat interface makes the same underlying agent accessible to non-technical users and
enables the "hand it work before bed, wake up to results" pattern.

**The moves:**
1. Front the agent with a chat channel people already use, so it's reachable anywhere.
2. Lean into proactivity — let it monitor and surface things, not just respond.
3. Pair chat with a simple dashboard/log so you can review actions and deliverables.
4. Match the interface to the audience: terminal for devs, chat for broad usability.

**Watch out for:** Convenience hides risk — if you only ever talk through chat, you
may never look at the files, structure, or actions the agent is actually producing.
Ambient access to a high-privilege agent amplifies whatever access you granted it.

**Original example to invent:** Source demoed a messaging-app assistant with a status
dashboard. Writers should design a different ambient-assistant use case and note the
"never inspecting the work" risk it introduces.
