# What Claude Code skills are and why they create leverage

**What:** A skill is a reusable, saved set of instructions an agent can trigger on
demand — effectively a written procedure (an SOP) that an agent reads and then
executes. Skills are not just text generators; they can run scripts, call APIs,
create artifacts, and delegate to sub-agents.

**Why it matters:** Writing a process once and saving it as a skill gives you far
more consistent results than re-prompting each time, and it turns individual
know-how into org-wide capability: one person's best way of doing something
becomes something the whole team (and its agents) can run with a single command.

**The moves:**
1. Notice a process you repeat, or a prompt/rule you keep restating.
2. Capture it as a skill so any run follows the same steps.
3. Trigger it by name or in natural language whenever you need that outcome.
4. Reuse across team members and even across compatible agent products, since the
   format is mostly plain markdown.

**Watch out for:** Skills you download from others can carry malicious
instructions — review before running. The consistency benefit only compounds if
the skill is actually reused; a one-off task rarely justifies one.
