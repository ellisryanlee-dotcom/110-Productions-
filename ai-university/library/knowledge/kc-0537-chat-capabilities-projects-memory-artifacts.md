# Getting real work from chat: projects, memory, connectors, files, artifacts

**What:** A cluster of chat-level capabilities that move an assistant from a stateless Q&A box to a work tool: **projects** (a persistent workspace with reference docs and a system prompt so every chat starts preloaded), **memory and past-chat search** (continuity across conversations), **connectors** (OAuth links to tools like drive/email/chat/calendar so it fetches instead of you pasting), **file creation** (real spreadsheets, decks, docs, PDFs you can download and send), and **artifacts/inline visuals** (interactive tools and charts built in-conversation, some with persistent storage and shareable links).

**Why it matters:** Most people stay stuck treating chat as a search bar and miss that it can hold context, plug into their existing tools, and produce actual deliverables. Using these turns chat into something that remembers you, pulls live data, and hands back finished work — reportedly saving hours a week.

**The moves:**
1. Create a project for anything recurring; drop in reference docs and a short system prompt about who you are and how you want responses.
2. Rely on memory/past-chat search so you stop "starting from zero" each session.
3. Connect the tools you already use (via OAuth) and ask the assistant to pull/summarize instead of pasting.
4. Generate downloadable files when you need a deliverable, not just a brainstorm.
5. Build artifacts/visuals for interactive tools or data views; note some persist data and can be shared by link.
6. A cheap upgrade: paste screenshots — the assistant can read images.

**Watch out for:** Free vs. paid varies by capability (some, like memory/file creation/inline visuals, are broadly available; others like past-chat search or persistent artifact storage are paid). The ceiling: chat still can't act on your machine — you're copying outputs into other tools yourself.

**Original example to invent:** The source describes a project recalling a prior decision and building a feedback-tracker artifact. Writers should invent a different project + artifact scenario (e.g., a recurring content calendar).
