# Interviewing yourself to extract tacit knowledge

**What:** Using an agent skill that relentlessly interviews you about a topic —
generating a structured brainstorm/notes file and only stopping once it has captured
everything — to get knowledge out of your head and into your system.

**Why it matters:** A common misconception is that a second brain fails because retrieval
is bad. Often the real gap is that the knowledge was never fully externalized. An
interview skill forces the tacit detail out of your head so the system actually has the
nuance to work with.

**The moves:**
1. Run the interview skill on a topic (a client, a business, a process).
2. Answer its relentless questions; feed it supporting files (transcripts, contracts,
   docs) as fodder.
3. Let it write the captured material to a structured file.
4. Use that as the raw data to build up a richer store — a wiki, or the input a knowledge
   graph needs.

**Watch out for:** Before blaming the AI for poor recall, check whether your folders
actually contain the full nuance that's in your head. Be mindful that anything you feed a
hosted model is processed by that provider — for sensitive/client data, consider local or
open-source models instead.

**Original example to invent:** Source adapted an existing "interview me" skill. Writers
should show self-interviewing to capture a different body of knowledge.
