# Package and anchor your offers into tiers

**What:** Instead of quoting a single number, present tiered packages (e.g.,
starter / growth / scale) so the client self-selects, and lead with the highest
tier as an anchor. The top price reframes the middle option as the sensible
choice, and tiering makes you look like a professional service rather than an
hourly freelancer.

**Why it matters:** A lone number invites comparison shopping and haggling. Three
tiers with a high anchor make pricing feel logical and steer most clients toward
your intended middle package — the classic anchoring effect working for you.

**The moves:**
1. Design three tiers with clearly different scopes/functionality.
2. Set the top tier as a deliberate high anchor you're happy to sell but expect
   few to take.
3. Present the top tier first so the middle (your target) feels like the smart,
   affordable choice.
4. Make each tier's included functionality explicit so the value ladder is legible.

**Watch out for:** Packaging + anchoring stops clients from benchmarking you
against hourly rates — but only if the tiers show real differences in outcome, not
just hours. Pair with clear scope definitions (see the traps card) so a "yes" to a
tier is a bounded commitment.

**Original example to invent:** Source anchored a high scale package against a
mid-tier target. Writers should design a different three-tier offer with invented
scopes and prices.
