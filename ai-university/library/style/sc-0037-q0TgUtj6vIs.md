# Hook (0:00–0:30)
Cold reveal / bait-and-switch pattern: opens by walking through what looks like a
famous brand's polished website, then reveals he built it himself with Claude Code
in ~30 minutes. Immediately promises the exact process plus free assets so even a
first-timer can replicate it.

# Beat map
- 0:00 fake-out product-site demo → reveal → promise + free-skill offer
- setup: install VS Code, Claude Code extension, open a folder, drop in the skills
- explain the two skills (front-end design + video-to-website) and project layout
- concept aside: animations are just video frames mapped to scroll
- generate source media (image model start/end frames → image-to-video)
- plan-mode build of the landing page → localhost test → iterate on feedback
- explainer aside: localhost vs the cloud (why deploy)
- deploy pipeline: GitHub + Vercel, hit a frames-gitignore bug and fix it live
- business framing: sell $5–10k sites + recurring hosting → community CTA

# Retention devices
The brand fake-out as a curiosity gap; repeated "even if you've never opened this
before" reassurance to retain beginners; live bug + fix as authenticity; frequent
"here's why this matters" asides that justify each step; teasing a related video
(skills) as an internal loop.

# CTA placement
Free-asset hook stated early and repeated (skills live in the free community).
Business-opportunity framing near the end doubles as motivation; paid-community
and like asks close the video.
