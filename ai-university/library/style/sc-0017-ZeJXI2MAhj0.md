# Hook (0:00–0:45)
Big-shift, urgency-driven opener: declares a new phase of AI automation has begun, contrasts the old drag-and-drop way with the new natural-language way, and adds a fear-of-being-left-behind stinger backed by an adoption statistic. Previews the payload: why this is happening, why you should learn it, and how to build one in minutes. The title itself is a provocative "stop doing X, do Y" frame.

# Beat map
Argument + demo hybrid over ~18 min. Roughly: hook/thesis → "what's changing" (how vs. what building) → market-size and adoption evidence → the three-waves history → a side-by-side of building the same automation the old way vs. describing it to an agent → live/recorded demos (a scheduled digest, a task-triggered research agent) → "why isn't everyone doing this" (four failure modes + fixes) → "your old skills still matter" reassurance → a full live one-shot build → recap and dual community CTA.

# Retention devices
- Provocative title/thesis creates a stance viewers want resolved.
- Statistics and market projections repeatedly re-raise stakes.
- Direct old-way-vs-new-way comparison makes the payoff tangible and visual.
- Reassurance beat (your n8n time wasn't wasted) defuses the anxiety the hook created, retaining the existing-tool audience.
- Live build with real errors getting auto-fixed provides authentic suspense and proof.

# CTA placement
Pointers to prior tutorials mid-video (for setup depth) act as internal retention links; main monetization deferred to the end — free community (positioned as having full courses on both the old and new methods) then paid community, closing on the standard outro.
