# Hook (0:00–~2:30)
Cold capability tour → live proof. Opens on the finished multi-agent system,
naming each specialist and its powers, then immediately runs live voice-command
demos that produce visible real-world results (a calendar invite appears, an email
sends). No throat-clearing; the promise is shown, not stated. A "download this free"
tease is planted early to hold viewers to the build section.

# Beat map
- Capability tour of the finished system (~0:00–1:00)
- Chained live demos, each escalating in complexity, narrated as they run
  (~1:00–8:00); each demo doubles as an explanation of one mechanism
- Community/free-template CTA break mid-video (~8:00–9:30)
- Deep build breakdown: inputs/outputs, orchestrator prompt, then each specialist
  and its tools in turn (~9:30–end)
- Abrupt, self-aware sign-off (notes he forgot to formally end).

# Retention devices
- Result-first demos before any theory — you see it work before you learn how.
- Open loop: "I'll show you how to download this for free" holds through the build.
- Each demo is a mini-cliffhanger ("let's see what happens") resolved on screen.
- Uses execution replays to peek inside what just happened, rewarding attention.
- Deliberately flags that prompts are "short and simple" to lower perceived
  difficulty and keep beginners watching.

# CTA placement
Single mid-video CTA bundled with the free-template payoff (join free community →
YouTube resources → download JSON), plus the paid community pitch appended right
after. End CTA is minimal (like/subscribe) due to the improvised sign-off.
