# Hook (0:00–~1:30)
Pattern: in-progress live demo as hook → payoff → promise. Opens mid-action ("I just pasted this in") spawning a three-agent team in parallel on screen, narrates the agents working and a QA agent kicking work back, then reveals the one-shot result (a polished landing page). Only after the payoff does it state the promise: what agent teams are, how to set up/use them, and when not to. Demo-first, explain-second structure.
