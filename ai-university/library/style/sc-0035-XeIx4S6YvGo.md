# Hook (0:00–0:30)
Trend-jacking myth-buster pattern: open by voicing the viral "X killed Y"
narrative, then immediately promise to actually test it and give a verdict. States
up front that this won't just be talk — it will be a head-to-head comparison
across defined categories. Verdict is previewed early (short answer: no), then
nuanced.

# Beat map
- 0:00 hook + framing the "will X kill Y" question, early verdict
- ~2:00 credibility insert (audience size, agency, enterprise work)
- ~2:30 lists the six comparison categories (agenda)
- category-by-category walkthrough, each ending in a numbered score and a running
  total (ease of use → triggers → agent tools → model support → UI components →
  deployment/control)
- ~final third: miscellaneous factors (pricing, evals, community), then a
  "when to choose each" summary
- closing philosophical riff (be tool-agnostic) → community CTA

# Retention devices
Running scoreboard after every section (open loop: "what's the final total?");
side-by-side screen demos doing the same task in each tool; explicit persona
caveat that keeps the "loser" relevant; asking viewers to check his math; a
category-per-chapter rhythm that resets attention.

# CTA placement
Soft credibility CTA early (community/agency mention as trust, not ask). Main ask
is back-loaded: after the verdict and the philosophy riff, he pitches the paid
community, courses, and a like request at the very end.
