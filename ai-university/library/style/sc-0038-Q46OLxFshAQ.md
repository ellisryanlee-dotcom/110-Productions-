# Hook (0:00–0:30)
Aspirational proof + reset pattern: opens with a personal income/age claim and
status markers, then resets the premise ("if I had to start over with nothing") to
make the blueprint feel universal. Promises real, actionable steps plus a scorecard
per stage — positioned against "all the other videos on this topic."

# Beat map
- 0:00 proof hook → start-over reset → promise of a staged blueprint + scorecards
- Stage 1 Freelancer: BUILD framework + member success story + scorecard
- Stage 2 Consultant: SCAN framework + solo-project story + scorecard
- Stage 3 Agency/Partner: GROW framework + readiness checklist + scorecard
- Stage 4 Teacher: SHARE framework + the funnel reveal + scorecard
- full-roadmap recap (staircase)
- pivot to offer: two-path framing (go alone vs join me) → long product pitch for
  the paid ecosystem, bonuses, price-anchoring

# Retention devices
Per-stage scorecards (speed / ease / income) as repeating structured payoffs;
named acronym frameworks the viewer can hold onto; embedded case-study stories to
concretize each stage; a staircase metaphor that promises a clear order; recap
before the pitch to reinforce value delivered.

# CTA placement
Value delivered first across all four stages, then a long, explicit sales close in
the final third (two-path framing, ecosystem breakdown, annual discount, price-goes-
up urgency, lifetime-rate lock). Free resource pack offered as the softer parallel
CTA.
