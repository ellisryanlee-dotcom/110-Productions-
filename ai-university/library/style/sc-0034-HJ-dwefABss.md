# Hook (0:00–~2:00)
Cold "mission control" flex. Opens on a live dashboard of multiple agents working in
parallel — a whole "company" the creator claims to run in ~30 minutes as a board, not
an operator. Names the two tools responsible and promises the viewer will be able to
either spin up a zero-human company or add an agent team to their business by the end.
The awe of many-agents-at-once is the hook; the promise is replicability.

# Beat map
- ~0:00–2:00 Dashboard flex + the board-not-operator framing + the end-state promise.
- ~2:00–5:00 What the tool is: open-source orchestration, key features (bring-your-own
  agents, goals, heartbeats, budgets, multi-company, ticketing), why it blew up (the
  many-terminals pain point).
- ~5:00–7:00 Resource plug; then start a brand-new company from scratch on screen.
- ~7:00–13:00 Live build: onboard a company, create the first agent, pick a model, run a
  test, assign the first task; deep-dive on heartbeats and the agent's instruction files
  (identity/heartbeat/persona/tools).
- ~13:00–18:00 Growing the org: approve a hire, spawn more agents, create a project/repo,
  add issues as the board, install skills, set up a routine, adjust approval settings.
- ~18:00–20:00 Advanced flexes: importing pre-built company templates, secrets handling
  via the companion coding agent, querying all companies; wrap-up.
- ~20:00–20:33 Resource CTA + like ask.

# Retention devices
- The opening dashboard is a "how is this possible?" artifact that seeds curiosity for
  the whole build.
- Guided click-by-click build with visible progress (agents appearing, tasks spawning).
- Layered reveals: each section unlocks a more powerful capability (single agent →
  hiring → skills → routines → importing whole teams), escalating the "wow."
- Recurring meta-thread: using a companion coding agent to understand the tool, paid off
  repeatedly (secrets, migration) as an open loop.
- Concrete relatable pain point (too many terminals) to justify the tool early.

# CTA placement
Mid-build resource plug (~5:00) offering a free setup guide in the community — placed
right before the hands-on section as a natural break. End CTA repeats the free-guide
offer and the standard like ask. Sponsor/tooling mentions are light; the primary
conversion is the community resource.
