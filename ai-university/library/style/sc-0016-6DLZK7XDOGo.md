# Hook (0:00–0:30)
Simplicity/accessibility promise (the title's "teach a 10 year old" framing): states it will explain, as simply as possible, what an agent is, its components, how it acts, and then build a real one in minutes. Sets an expectation of speed and ease ("surprised how quick you can spin one up") to lower the barrier for beginners.

# Beat map
Concept-then-build structure. First half: a diagram-driven explainer walking the agent's parts (brain, memory, instructions, input, tools, output). Second half: a step-by-step live build in a no-code platform — add agent, add model + credential, add memory (test it), add an email tool with dynamic fields, write the system prompt (via an LLM helper), test a send, then extend with a contact-database tool, then read the logs. Ends with "where you can take this next" (swappable I/O) and a community CTA.

# Retention devices
- A visual diagram as a spine the narration keeps returning to, mapping abstract parts to the concrete build.
- Live, real-time demonstration ("we'll see this in live time") with visible success/failure creates suspense.
- Deliberate broken-then-fixed beats (agent has no memory → add memory → re-test; wrong sign-off → fix prompt → re-run) model the real iterate loop and pay off small loops.
- Log walkthrough at the end reinforces understanding by replaying what just happened.
- Incremental complexity (one tool → contact lookup) gives a sense of building momentum.

# CTA placement
Mid-video soft mention of a helper resource (a custom prompt-writing tool) and the community while building, folded into the workflow rather than interrupting it; standard like/comment/outro at the end. CTAs are lightweight and woven into teaching moments.
