# Hook (0:00–~1:30)
Cold, impressive artifact demo. Opens mid-scene showing a fully built, personified
always-on assistant with its own accounts and a live dashboard — a "wait, what is
this?" flex — quantified by an eye-catching effort stat (hours + tokens). Then pivots
to the thesis: much of this could be done in a tool I already understand, so let's
compare them fairly. The hook sells the dream, then promises honesty.

# Beat map
- ~0:00–2:00 Artifact demo + framing the two tools + why this comparison.
- ~2:00–4:00 Define both tools; show a trend chart of their rising attention; note the
  rename.
- ~4:00–6:00 Side-by-side same-task demo kicked off on both, to be revealed later.
- ~6:00–20:00 The scored rubric: eight metrics, each given a number for both tools with
  reasoning (out-of-box, setup/risk, cost, power/access, security, usability, ROI, ICP).
  Running score tally announced after each round.
- Woven in: the deferred demo payoff (both deliverables compared), real tweets/reports
  as evidence (esp. the security section), sponsor mention during setup/hosting.
- ~20:00–22:00 Verdict, nuance ("who each is for"), hype self-awareness, and a closing
  word delivered in-character by the assistant.

# Retention devices
- The running scoreboard is the spine — a gamified tally that creates "who's winning?"
  tension across the whole runtime, including deliberately noted ties.
- Deferred demo: kicks off both tasks early, promises the reveal, pays off mid-video.
- External proof (screenshots of tweets/reports) raises stakes in the security beat.
- Personified assistant given "lines" bookends the video (intro and outro), a
  recurring character device.
- Honesty/hype-check framing keeps a skeptical viewer engaged rather than bouncing.

# CTA placement
Native sponsor read integrated where it's contextually relevant (the hosting/setup
metric), including a discount code. Community CTA near the end tied to the "if you like
this style of thinking" angle; standard like ask in the outro. The in-character outro
doubles as a soft motivational CTA.
