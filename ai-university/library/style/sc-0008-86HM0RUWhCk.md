# Hook (0:00–~1:30)
Promise + inclusivity framing. States the payoff (websites that don't look AI
vibe-coded) and immediately reassures total beginners they can follow along,
widening the audience. Structures the whole video as a numbered list of "5 hacks,"
which sets clear expectations and a progress bar.

# Beat map
- Zero-to-setup: install the IDE, add the coding-agent extension, open a project
  (~1:30–5:00)
- Hack 0: the project instructions file as prerequisite (~5:00–7:00)
- Hack 1: the design skill (what skills are, install, one-shot demo) (~7:00–12:00)
- Hack 2: the screenshot self-review loop (~12:00–15:00)
- Hack 3: cloning a reference site from screenshot + styles (~15:00–20:00)
- Hack 4: individual components from a library (~20:00–23:00)
- Deploy pipeline (GitHub → host, local vs pushed) (~23:00–27:00)
- Recap of the five hacks + community CTA + sign-off.

# Retention devices
- Numbered-list structure (with a cheeky "number zero") gives a visible progress
  bar that pulls viewers through.
- Each hack ends in a live reveal ("let's refresh and see") — repeated payoff beats.
- Plants a "secret thing you may not have noticed" callback (the screenshots) to
  reward attentive viewers and bridge to the next hack.
- Teaches the failure mode too (screenshot loop over-engineering on animations),
  which builds credibility.
- Beginner reassurance recurs so advanced topics don't scare off the target viewer.

# CTA placement
Free artifact (the instructions file) offered early and again at recap; paid-
community pitch bundled into the closing recap before a standard like/sub sign-off.
