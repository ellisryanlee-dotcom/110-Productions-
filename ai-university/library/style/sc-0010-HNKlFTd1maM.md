# Hook (0:00–~0:45)
Big proof number + relatability + tease-the-end. Opens with the headline result
(four agents, $23,000, from four businesses), immediately lowers the barrier ("as a
beginner… you could build these"), and tells viewers to stay for the most expensive
build — an explicit end-loop planted in the first breath.

# Beat map
- Agent 1: outreach agent — what it did, price, ROI math, how it was sold
  (~0:45–4:00)
- Agent 2: sales/quote agent — value prop, price, team-based sales process
  (~4:00–7:00)
- Agent 3: internal assistant — harder-to-price value, honest pricing critique
  (~7:00–10:00)
- Agent 4: full concierge — most complex/expensive, the promised payoff
  (~10:00–11:30)
- The repeatable 7-step roadmap (diagnose, tools, ROI math, package/anchor, avoid
  traps, prototype/QA, partnerships) (~11:30–13:30)
- Resource + community CTA + sign-off.

# Retention devices
- Ascending price ladder ($1.6k → $4k → $6k → $12k) is its own suspense curve,
  reinforced by the opening "stay for the most expensive one."
- Vulnerability/authority mix: openly admits early mistakes (random pricing,
  forgetting baseline data) which builds trust and teaches simultaneously.
- Each agent segment follows a consistent template (what/price/how sold), giving
  predictable rhythm.
- Ends by consolidating everything into a numbered framework — a save-worthy payoff.

# CTA placement
No hard mid-roll; funnel is light through the teaching. Single resource-pack +
community CTA at the end alongside a course mention, then a standard like/sub
sign-off. Shortest of the batch, tightly paced.
